# 安装和启动

这是通用 Agent Skill。把整个包交给支持 Skill 和本地工具的助手，安装后说“使用我的工作流，启动工作台”。助手从安装目录运行 `python scripts/workflow.py init --open`，Windows 可用 `py -3`。

Codex 可通过内置 Skill 安装器安装 GitHub 仓库，当前标准用户目录是 `~/.agents/skills/`。WorkBuddy 可通过“专家·技能·连接器 → 技能 → 添加技能 → 上传技能”导入 ZIP；不要假设所有版本都能通过一句 GitHub 链接安装。其他支持 SKILL.md 的助手按其文档安装。普通聊天环境可以复制阶段模板，不会因此获得本地工具权限。

首次启动后，在工作台点击“连接工作目录”，选择助手创建的 `MyWorkflow` 文件夹。配置、剧目、分镜和规则都保存在其中的 `workspace.json`，素材分项目保存。Chrome、Edge 等支持目录读写的浏览器可直接保存；不支持时导入 JSON、编辑后导出，再让助手用 `import-state` 导入。页面会显示当前保存方式。

常用对话：

- “启动我的工作流工作台，数据放到这个目录。”
- “新建一部短剧，先和我确认故事与人物资产，再拆分镜。”
- “按项目的文戏预设生成这三镜，总计不超过三十秒。”
- “第 S03 镜视线不对，只重做这一镜，其他保留。”
- “把这次的避坑经验记到这个项目；把我明确的审美偏好存成全局规则。”

工作台不内置模型和算力。ComfyUI、模型权重、AI 助手权限由用户已有环境提供。工作台本身没有后台服务，不需要 Node.js；Python 负责文件操作和 API 请求，FFmpeg 负责视频检查与基础拼接，Remotion 是可选的剪辑工具。
