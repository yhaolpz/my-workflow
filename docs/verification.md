# 验证范围

版本：0.1.1。验证日期：2026-11-13。

## 已完成

- Python 工具的 17 项测试：配置保留、路径边界、项目隔离、真实槽位映射、批次预算、任务去重、丢失响应后不盲目重发、指南失败回退和审片后拼接。
- JavaScript 的数据契约、模板上下文、路径与转义检查。
- macOS 已安装的 Google Chrome 通过 `file://` 打开工作台，完成新建项目、编辑故事、导入 API 图、配置槽位、保存规则、复制项目模板和导出 JSON。
- 浏览器实际导出的 JSON 由 Python 导入并重新读盘，确认页面与助手可以交换同一份配置。
- 桌面九个视图与手机宽度检查，无横向溢出；浏览器运行无页面异常。
- H3 官方指南与两份模式参考文本实际拉取成功，记录来源、日期和 SHA-256。

## 需要区分的结果

模拟 API 测试验证提交与恢复逻辑，没有运行真实 GPU 生成，也不证明某套第三方节点和权重可用。首次接入必须在实际 ComfyUI 上运行只读检查，再按授权范围试跑。

目录授权接口在 macOS Chrome 的本地文件环境中可用。原生目录选择器尚未纳入自动化端到端测试；已验证的备用路径是“导出 JSON → 助手导入”。直接保存按单写入者使用，页面和助手不要同时修改同一份配置。

Windows 与 Linux 的命令行兼容性由仓库 CI 分别运行；操作系统的真实桌面交互仍须在对应设备上验收。视频画面、口型和情绪需要具备视听能力的助手或用户实际复核，技术解码通过不等于内容通过。
