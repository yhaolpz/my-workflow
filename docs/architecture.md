# 我的工作流：实现与使用边界

面向希望使用现有 AI 助手制作短剧的个人创作者。交付形式是可安装的 Skill、纯静态工作台和跨平台 Python 命令行工具。工作台负责组织和审阅，AI 助手负责推理、调用工具和执行；ComfyUI 负责生成。

## 已核对的依据

| 确定结论 | 依据 | 尚未确认的部分 | 实现范围 |
|---|---|---|---|
| 原有个人 Skill 的执行器依赖 Seek 和桌面配置 | `skills/comfyui/SKILL.md`、`tools/comfyui/client.py` | 其他用户的目录、节点和权重 | 独立配置和独立客户端，不打包个人连接 |
| HTML 的目录读写需要用户授权，浏览器支持有差异 | MDN showDirectoryPicker、Chrome File System Access 文档 | 用户选用的浏览器与权限 | 文件夹连接优先；JSON 导入导出作为备用 |
| `/prompt` 接受 API 节点图，不接受只填名称的工作流 | ComfyUI Server Routes | 用户自定义节点、模型和参数 | 导入 API JSON，显式绑定提示词、时长和参考素材 |
| H3 的基础模式和全参考模式采用不同提示词结构 | MiniMax 官方 h3-prompt-writing Skill | 官方未来修订 | 保存官方链接、按模式刷新缓存，失败保留上次成功版本 |
| WorkBuddy 支持自定义技能包上传 | WorkBuddy 官方技能文档 | 每一版本是否支持从 GitHub 对话安装 | 同时提供 GitHub 目录和 ZIP；不承诺统一安装路径 |

## 四个环节

1. 定剧本和分镜：故事、人物与场景资产、镜头卡、生成提示词集中在项目内；人验收，AI 扩写和整理。
2. 自动生成：每个预设绑定一份真实 API 工作流，文戏和动作可以使用不同图或不同参数覆盖。名称只是标签。提交前核对节点、引用和预算，保存任务 ID。
3. 查错、剪辑和验收：技术检查与视觉审查分别记录；只采用已通过的取用段。支持 FFmpeg 基础拼接，或由 AI 按模板生成 Remotion 工程。重做有次数上限，异常提交不盲目重发。
4. 规则复用：用户的避坑经验与审美偏好保存在工作目录，区分全局和项目，不随 Skill 更新被覆盖。

## 本地结构与同步

默认工作目录为用户主目录下的 `MyWorkflow`，可在启动命令中更换。`workspace.json` 是 AI 和工作台共用的数据来源；项目素材位于 `projects/<id>/`，工作流位于 `workflows/`，官方指南缓存位于 `guides/`，任务收据位于 `jobs/`。这些文件不属于安装包和公开仓库。

启动命令复制静态 HTML、CSS、JavaScript 到工作目录并打开本地文件，不运行后台服务，不依赖 Node.js。页面通过文件夹授权读写相同的 JSON；不把只存在浏览器 localStorage 的状态当成 AI 已可读取。页面显示保存方式与未导出状态。浏览器不支持目录授权时，可导入 JSON 并导出更新文件，再交给 AI 导入。

CLI 写入采用独占锁、版本号和原子替换；页面保存前检查锁和版本号，发现外部变更要求刷新。工作目录按单写入者使用，不同时编辑同一份配置。刷新快照后重新载入页面可看到 AI 的新增产物。

## 执行依赖

浏览工作台只需浏览器。自动执行需要能读写文件和运行命令的 AI 助手，以及 Python 3.10+。视频检查和基础拼接需要 FFmpeg/ffprobe；选择 Remotion 时另需该工具的运行环境。纯网页聊天可以使用模板与导出资料，不能仅凭模型名称认定具备本地执行能力。

界面不会绕过跨域访问限制直接控制 ComfyUI，也不会内置聊天模型 API。实际请求由助手调用本地 CLI 发起。认证令牌通过环境变量读取，工作台只保存变量名。缺少节点、权重或认证时给出具体缺口，不自动安装云端组件。

## 验收

检查本地持久化、工作流导入和参数映射、任务去重与恢复、素材路径、项目隔离、规则读取、官方指南刷新失败回退、基础剪辑和静态页面交互。模拟 ComfyUI 测试不等同于真实模型生成成功。平台兼容结论区分源码设计、自动化测试与实际设备验证。
